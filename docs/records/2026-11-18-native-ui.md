# 自有 UI 与 DSH 原生待办

日期：2026-11-18（Asia/Shanghai）。隔离候选沿用 DSH `0.2.2-rc.3`、`isla-test` 和艾拉角色 bundle `0.2.0`。PDF 使用阶段 4 的应用网关路径。本次验收使用合成身份、合成 PDF 和本地模拟模型。

## 接法

艾拉的 Cordis bundle 继续提供人物上下文与记忆接口。DSH 的 `session/prompt` 路径执行普通聊天、模型调用和工具循环。网关负责认证、会话绑定、历史与附件权限，并把网页需要的 DSH 事件写入所属会话的任务记录。网页、PWA 和 Android TWA 共用聊天界面。

试点 `giftia-native-todo-bundle@0.1.0` 直接挂载随锁定 DSH 提供的 `@deepseek-ai/dsh-tool-todo`。`agent/created` 在模型选工具之前通过已有的回环角色服务核对当前会话。搭档的普通聊天可用 `todo_write`。访客、PDF 问答和无对应授权的会话通过 DSH 工具作用域关闭此工具。网关每轮保留最近一份清单快照，最多展示 12 步，每步文本最多 160 字符。网页显示步骤、状态和本地化工具反馈。正文继续使用该轮带艾拉人格指引的模型回复。

参考陪伴插件把 DSH 会话事件转换成工作状态的做法。艾拉用于显示工具和任务进度，保留原有 07 标识和聊天角色。 [陪伴主题](https://dshmk.com/topics/companion) · [DSH Desktop Pet](https://github.com/sereinmono/dsh-desktop-pet) · [DSH Host 网关](https://deepseek-harness.github.io/deepseek-harness/en/reference/api-gateway)

网页重做了登录、欢迎页、聊天气泡、输入框、资料抽屉及页码面板。桌面显示资料侧栏，手机从「资料」打开附件。聊天中的页码可以展开对应页正文，已选附件和 PDF 问答可在刷新后恢复。工具状态独立显示短句，包括「我算一下…」与「步骤已更新」。

