# 分步执行提示词

编写日期：2026-11-05。本文件是 [统一未来计划](ROADMAP.md) 的执行辅助材料，**不维护另一套计划或任务状态**。发生变化时以路线图、最新记录与源码为准。

## 使用方法

在新窗口打开 `D:\ai chatbot`。先粘贴下面的「通用开场」，再粘贴一个任务的提示词；也可以让新窗口直接读取本文件并执行指定 ID。不要一次要求执行全部任务。

主线建议依次执行：`F1 → F2 → F3 → C1 → C2 → C3 → C4 → G1 → G2 → G3 → R1 → R2`。具体依赖以路线图为准，前置未通过时先完成可独立工作，说明剩余依赖。工程增强可按路线图独立穿插；远期条目满足触发条件才启动。
