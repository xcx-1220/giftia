# Giftia · 一个会遗忘的陪伴型对话内核

以《可塑性记忆》为灵感的个人陪伴项目，角色为艾拉。寿命、记忆、遗忘、关系成长、梦、主动联系和回收换代由程序与数据库实现。

Python 3.11+ 标准库 + SQLite；原生 HTML/CSS/JavaScript PWA；安卓 TWA 加载同一个网站。一个进程维护一个艾拉和一个搭档，访客拥有独立记忆分区。

## 本地体验

在项目根目录运行，Python 运行时无需安装第三方包：

```powershell
python tools/demo_life.py
python tools/selftest.py
python run.py --mock
```

演示与自测使用隔离数据；`run.py --mock` 则会使用并更新项目本地 `data/`。正式服务运行时不要再启动指向同一数据库的第二个实例。真实模型、网页启动和配置方式见[开发与使用](docs/DEVELOPMENT.md)。
